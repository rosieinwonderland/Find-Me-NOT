# Find Me Not

**Find Me Not** is a cyberpunk-inspired web app for encrypting and decrypting text locally in your browser.  
All data stays on your device — no servers, no tracking, no traces.

### ✨ Features
- AES-GCM 256-bit encryption
- Password/key required to encrypt and decrypt
- Works entirely offline
- Neon purple cyberpunk theme

### 🚀 Usage
1. Open `index.html` in your browser.
2. Enter text and a key → click **Encrypt**.
3. Copy the encrypted text to share.
4. Recipient enters the same key and clicks **Decrypt**.
